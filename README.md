# MDPad 下載

輕量、免安裝的 Markdown 多檔編輯器：左側檔案總管與大綱、右側多分頁編輯與即時預覽。目前最新版本：**v2.0.0**

## ⬇ 直接下載（點檔名就開始下載）

| 下載 | 系統 | 種類 | 說明 |
|---|---|---|---|
| **[MDPad-2.0.0-win-x64-setup.exe](https://github.com/leowei813/MDPad-Releases/releases/download/v2.0.0/MDPad-2.0.0-win-x64-setup.exe)** | Windows | 安裝版 | Windows 10／11（x64）。安裝到目前使用者、不需系統管理員；雙擊 .md 直接開啟 |
| **[MDPad-2.0.0-win-x64-portable.zip](https://github.com/leowei813/MDPad-Releases/releases/download/v2.0.0/MDPad-2.0.0-win-x64-portable.zip)** | Windows | 可攜版（建議） | Windows 10／11（x64）。解壓後執行 MDPad.exe；設定存在旁邊的 data\，可放隨身碟 |
| **[MDPad-2.0.0-win-x64.exe](https://github.com/leowei813/MDPad-Releases/releases/download/v2.0.0/MDPad-2.0.0-win-x64.exe)** | Windows | 單一執行檔 | Windows 10／11（x64）。不需安裝；設定存在使用者資料夾 |

- 版本說明與歷史版本：**[最新版本頁面](https://github.com/leowei813/MDPad-Releases/releases/latest)**
- Windows 不確定選哪個：要放隨身碟或不想安裝 → 可攜版；想雙擊 .md 就用 MDPad 開啟 → 安裝版。兩者可以並存。
- 第一次在 Windows 開啟若出現「Windows 已保護您的電腦」：點「其他資訊」→「仍要執行」（程式未購買數位簽章憑證）。
- macOS 若顯示「無法驗證開發者」：在 Finder 對 MDPad.app 按右鍵 →「打開」。
